# GypsyLab8 Portfolio

Site portfolio consolidando projetos de arte, ciência e tecnologia open & free dos perfis [@gypsylab8](https://github.com/gypsylab8) e [@guimasan](https://github.com/guimasan), além de referências ao [gypsylab8.wordpress.com](https://gypsylab8.wordpress.com) e [gypsylab8.net](https://gypsylab8.net).

## Publicar no GitHub Pages

1. Crie um repositório no GitHub (ex.: `gypsylab8-portfolio` ou `gypsylab8.github.io`).
2. Envie os arquivos desta pasta para a branch `main`.
3. Em **Settings → Pages**, selecione a branch `main` e a pasta `/ (root)`.
4. Acesse `https://<seu-usuario>.github.io/<repo>/`.

## Atualizar projetos

Edite o array `gypsy` / `guima` em `index.html` para adicionar novos repositórios.
